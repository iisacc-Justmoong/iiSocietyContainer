# Windows 파일 목록의 provider 제어 디렉터리

Windows에서 점으로 시작하는 이름이 항상 hidden 속성을 뜻하지는 않는다.
재귀 디렉터리 열거는 제어 디렉터리 항목을 건너뛰어도 그 자식까지 방문할 수 있다.
최근 파일·이미지 목록은 section에 대한 상대 경로의 모든 구성 요소를 확인하여
provider 제어 디렉터리와 숨김 경로 내부를 제외한다.

회귀 검사는 실제 `.iisacc-file-provider` 아래 catalog·WAL·SHM 파일과 사용자 문서를
함께 만들고 사용자 문서 하나만 노출되는지 확인한다. 기존 검색·메타데이터·이미지
검사와 Helper의 캔버스 저장·미리보기 소비자도 함께 실행한다.
공유 저장소 검사는 Windows의 원문 실패 정보를 보존하도록
`build/shared-storage-qt.txt`에도 Qt 검사 결과를 기록한다.
파일 감시 통지 검사는 Windows 실제 I/O에서 약 3.55초의 완료를 확인하여 대기 한도를
3초에서 5초로 조정한다. 10초 fallback보다 먼저 완료되어야 하며, 명시적 refresh 없이
기대 행이 나타나는 조건을 유지한다. GUI 호출 자체의 비차단 시간 검사는 별도 유지한다.
