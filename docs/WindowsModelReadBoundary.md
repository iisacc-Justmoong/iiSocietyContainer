# Windows 모델 참조와 유지보수 읽기

NTFS의 미리보기 보조 스트림은 파일의 수정 시각을 공유한다. provider는 원래 시각을
복원하지만, 복원 전의 짧은 구간에서 읽은 시각을 모델 참조에 사용하면 실제 모델
내용을 변경하지 않아도 이전 참조가 무효가 된다. 모델 내용과 로컬 버전 시각은
provider `SourceAccess` 경계 안에서 새로 조회한다. 실제 내용 변경의 거절은 유지한다.

회귀 검사는 같은 모델에 64회 미리보기를 게시하는 동안 기존 참조를 64회 확인하고,
게시 완료 후에도 동일 경로를 반환하는지 검사한다. 이후 실제 모델 내용을 변경하여
이전 참조가 거절되는지도 확인한다.

유지보수의 manifest 읽기는 네이티브 provider `ReadFile`을 사용한다. Windows에서
삭제 공유가 없는 CRT 입력 스트림이 복제본 식별 정보의 원자적 교체를 막지 않도록
한다. manifest 크기 제한과 schema·식별 정보 검증은 유지한다. 유지보수를 동시에
실행하면서 복제본 식별 정보 채택·완료를 각각 64회 수행하는 검사도 실행한다.
각 전환에서는 네이티브 읽기 스냅샷을 열린 채 유지한다. 이 조건에서 기존 Qt 저장은
Windows의 액세스 거부로 실패함을 재현하였다. 기존 manifest의 레이아웃 갱신·복제본
채택·완료는 provider의 네이티브 원자적 교체 API로 저장한다. 새 패키지는 기존 생성
경로로 9개 section과 manifest만 만들며 CLI의 최소 구성 검사를 유지한다. 외부 읽기 핸들,
이전 식별 정보 검사와 프로세스 간 잠금은 유지한다.

공유 저장소 실패 원문은 `build/shared-storage-qt.txt`에 보존하며 복제본 준비 실패에는
생산 코드가 반환한 오류 메시지를 함께 기록한다. 호스트 전환 검사는 별도 fixture로
16회 실행하여 이전 검사의 상태를 재사용하지 않는다.
